Pre-Delivery Inspection: one service, then a platform

Context

PDI launched as a single-tenant service I owned end to end in Java/Spring Boot with PostgreSQL and MongoDB, config-driven pricing, and AWS Lambda report generation.

Decision

I re-architected it into a multi-tenant system on Kafka-driven event flows, with an ops dashboard for step-level tracking and intervention so operations could unblock orders without engineering.

Result

7,000+ orders a month across three platforms, code discrepancy down 8%, ops escalations reduced. A custom config CMS followed: 50% less dev involvement, iteration twice as fast.

The Vehicle History refactor cut error rates 30% — and moved order conversion ~2% and revenue ~5%.
