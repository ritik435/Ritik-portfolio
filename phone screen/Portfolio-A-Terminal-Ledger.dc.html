04 · Case study · Pre-Delivery Inspection

One service, then a multi-tenant platform.

01 · CONTEXT

PDI started as a single-tenant service I owned end to end in Java/Spring Boot with PostgreSQL and MongoDB, config-driven pricing, and AWS Lambda report generation.

02 · DECISION

I re-architected it into a multi-tenant system with Kafka-driven event flows and an ops dashboard for step-level tracking, so operations could unblock orders without engineering.

03 · RESULT

7,000+ orders a month across 3 platforms, code discrepancy down 8%, fewer ops escalations. A custom config CMS followed: 50% less dev involvement, iteration twice as fast.
