# Ritik Arora — Portfolio

Personal portfolio site. Backend engineer, ~4 years, Java & Spring Boot.

**Live:** [ritik-arora.vercel.app](https://ritik-arora.vercel.app/)

## Tech Stack

React 19, Vite, SCSS, Supabase, Express, Vercel

## Setup

```bash
npm install
npm run dev        # starts Vite + Express server
```

## Environment

Copy `.env` and fill in your values:

| Variable | Purpose |
|----------|---------|
| `VITE_SUPABASE_URL` | Supabase project URL |
| `VITE_SUPABASE_KEY` | Supabase anon key |
| `VITE_APP_ENV` | `staging` or `production` |

## Build

```bash
npm run build      # outputs to /build
```
